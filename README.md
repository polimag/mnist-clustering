# Кластеризация рукописных цифр MNIST

Сравнила K-means на исходных изображениях с кластеризацией по признакам двух свёрточных автокодировщиков. Восстановление изображений оценивала по SSIM, кластеризацию — по ACC после сопоставления меток кластеров с классами.

**PyTorch · K-means · SciPy · SSIM · ACC**

| Метод | ACC | SSIM |
| --- | ---: | ---: |
| K-means на исходных изображениях | 57,92% | |
| Автокодировщик № 1 и K-means | **61,31%** | 0,9054 |
| Автокодировщик № 2 и K-means | 59,50% | **0,9586** |

Лучший вариант повысил ACC на **3,39 процентного пункта**. Модель с более высоким SSIM показала более низкую точность кластеризации, чем первый автокодировщик.
